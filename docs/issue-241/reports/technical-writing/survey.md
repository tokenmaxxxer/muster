# Current-state survey — issue-241

## doc-type
This is a `reference`+`explanation` split, per Diátaxis: the README becomes almost
entirely `explanation` (the vision essay) plus a minimal `tutorial`-flavored
quickstart; everything else that is actually `reference`/`how-to` material
(requirements, config knobs, gates, commands) moves to `docs/handbooks/` as
reference/how-to documents. Mixing types in one file was the original problem —
this overhaul is a type split, not a rewrite of content.

## target reader
README.md/README.ko.md readers are a first-time visitor deciding whether to install
and to whom to explain "what is this." They are not yet operating the tool. The
handbook readers are already-committed users configuring or debugging the tool —
different job, different doc.
