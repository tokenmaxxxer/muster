## What was done

Classified all 57 closed issues #310–#441 into Deployed surface / Repo-local / Prose-only by locating each issue's closing PR (via `closedByPullRequestsReferences` or a `timeline` cross-reference match) and reading its actual changed-file list, then wrote the classification table, per-row follow-up recommendations, and a summary of category-2/3 items needing action.

## Why

Phase-2 execution of issue #444: the operator needs to know, for every closed requirement, whether a consumer installing the plugin actually receives the fix (`on-the-record/commands|hooks/**`) or only this repo gets it (`gates/`, workflows, other repo-root paths) or gets nothing but a document (`docs/`) — this table is the evidence base for deciding what to port through #441's new enforcement mechanism.
